## 1. 项目定位

- 内网、短期、轻量：把已配置好的 OpenAI **文生图**能力转发给同事。
- **不用** `openai-agents` SDK；agent = `config.yaml` 里的路由条目。
- 出图调用官方 `images.generate`；响应尽量原样返回。
- 鉴权：配置文件配死账号密码（不做哈希/会话）。
- 日志：项目下 txt，只记请求与用量字段，**不记返回体**。
- 并发：最多 **5** 个工作线程。

## 3. 接口规范

### `GET /health`
- 无参数、无鉴权
- 返回：`{"status":"ok"}`
- 不探测上游 OpenAI

### `GET /agents`
- 无鉴权
- 返回当前配置中全部 agent（本地视为存活，不探上游）
- 形如：`{"count":N,"agents":[{id,name,model,defaults,alive}, ...]}`

### `POST /query_GPT`
- Content-Type: `application/json`
- Body：

```json
{
  "account": "demo",
  "password": "demo123",
  "agent_id": "dalle-3",
  "ask_content": "工程示意图：红色立方体"
}
```

- 流程：验登录 → 验 `agent_id` → 线程池出图 → 写日志 → **原样返回**上游 dict
- 错误码约定：`401` 账密错；`404` 未知 agent；`400` 空 prompt；`502` 上游/调用失败

### 已注册 agent（默认配置）

| id | model | 返回形态注意 |
|----|-------|----------------|
| `dalle-2` | `dall-e-2` | 默认 `url`（约 60 分钟失效） |
| `dalle-3` | `dall-e-3` | 默认 `url` |
| `gpt-image-1` | `gpt-image-1` | 仅 `b64_json`，不要配 `response_format` |

## 4. 日志规范

文件：`logs/call_records.txt`（自动建）

列（TSV，缺省留空）：

`time | account | agent_id | agent_name | model | ask_content | total_tokens | input_tokens | output_tokens | note`

- **不写**接口返回（尤其不写 base64）
- `dall-e-2/3` 通常无 `usage` → token 列空，`note` 可能为 `no_usage_field`
- GPT Image 若带 `usage` 则尽量填 token 列

---

## 5. 配置规范

编辑 `config.yaml`（**勿把真实 Key 推到公共仓库**）：

1. `openai.api_key`：必填才能出图  
2. `openai.base_url`：官方或兼容网关  
3. `users`：同事账号密码列表  
4. `agents`：新增模型就加一条（`id` / `name` / `model` / `defaults`）  
5. `concurrency.max_workers`：默认 5
